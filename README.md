# 易经算卦

在浏览器里演一卦。点开后天八卦，八卦先转动，再收成一个点，卦象从那个点放大，然后展开卦辞和卦批。六爻仍按铜钱法在背后生成。

此为周易文化体验，不是对人事的断言。

## Mac 应用

`npm run pack:mac` 会打出两个压缩包，放在 `public/download/`：

- `yijing-mac-apple-silicon.zip`：Apple 芯片的 Mac，包括近几年的 Mac mini。
- `yijing-mac-intel.zip`：Intel 芯片的 Mac。

解压后得到「易经算卦.app」。第一次打开时，在访达里对它按住 Control 再点「打开」。这不是 App Store 里的签名安装包。

应用窗口就是桌面版：点八卦，先旋转，再收成一个点，卦象从那个点放大，然后出现卦批。空格或回车也可以起卦。

## 三种外壳

网页仍然是同一套界面。

- **Mac**：宽屏幕上的桌面版。八卦居中，写着「点击八卦起卦」。空格或回车也可以起卦。读完之后，用「再占一卦」回到八卦。
- **iPhone**：桌面版里可以切到 iPhone 预览，外面有一道手机框和灵动岛。窗口窄于 840 像素时，界面铺满屏幕，不再套假手机壳。标题居中，底部按钮是胶囊形。
- **Android**：同样可以在桌面预览，或在窄屏里全屏使用。标题靠左，底部按钮是圆角矩形，预览框上方有打孔摄像头。窄屏时用浏览器的 userAgent 区分 iPhone 和 Android。

手机版仍是浏览器里的壳，可以添加到主屏幕。Mac 应用是上面的「易经算卦.app」。

## 铜钱怎么算

一次掷三枚。阳面计三，阴面计二。

| 点数 | 名称 | 爻 |
| --- | --- | --- |
| 六 | 老阴 | 阴，变 |
| 七 | 少阳 | 阳 |
| 八 | 少阴 | 阴 |
| 九 | 老阳 | 阳，变 |

六爻自下而上。动爻翻转后得到之卦。
